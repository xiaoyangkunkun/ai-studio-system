flowchart TD

    C --> D[2:30 产出目录Watchdog]

    E --> F[3:10 知识库健康度扫描]
    F --> G[3:30 知识库整理]

### 依赖关系（已配置 context_from）
- Token用量结算 → 独立（脚本直出）
- 晚间复盘 → 依赖 Token用量结算（usage 数据注入）
- 习惯整理 → 依赖晚间复盘（复盘结果作为画像更新依据）
- 知识库整理 → 依赖 Inbox AI分类（分类结果注入）
- 夜间任务检查 → 依赖知识库整理（验证整理完成）
- 晨报 → 独立（汇总全天产出）

## 待答复追踪

```mermaid
flowchart TD
    A[军师提多个问题] --> B[每个问题建 Notion 记录]
    B --> C[状态=待答复]
    C --> D[老大答一个]
    D --> E[军师标完成+提醒剩余]
    E --> F{还有未答?}
    F -->|是| G[继续等/晨报提醒]
    F -->|否| H[全部关闭]
    G --> I[超过24h晨报自动提醒]
```

### 规则
- 多个问题必须编号（Q1/Q2/Q3）
- 每个问题建 Notion 待答复记录
- 用户答一个 → 标完成 + 提醒剩余
- 晨报每日展示未答问题
- 超过 24h 未答 → 晨报自动提醒

### 工具
- 添加：`python3 pending_reply.py add "问题" "备注"`
- 查询：`python3 pending_reply.py list`
- 完成：`python3 pending_reply.py done <page_id>`
