# 📥 Inbox 收件箱

所有新笔记先进入此目录，由AI自动分类到对应位置。

## 使用方法

1. 新建 `.md` 文件放入此目录
2. 每天凌晨3:00 AI自动分类（Inbox AI分类定时任务）
3. 分类后文件会移动到 `wiki/` 或其他目录

## 分类规则

| 类型 | 目标目录 |
|------|----------|
| 实体（人/物/组织） | wiki/entities/ |
| 概念（方法/理论） | wiki/concepts/ |
| 对比（方案比较） | wiki/comparisons/ |
| 原始素材 | wiki/raw/ |
| 流程文档 | 流程/ |
| 工作室产出 | 工作室产出/ |
| 复盘 | 复盘/ |

## 注意事项

- 文件名建议有意义（不要用无意义的临时名）
- 可以在文件开头添加 frontmatter 指定分类
- 已分类的文件会被删除，请勿在此目录存放重要文件
