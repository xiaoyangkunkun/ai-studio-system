# 环境依赖说明

> deploy.sh 会自动安装这些依赖，了解底层有助于排查问题。

## 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| 操作系统 | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |
| CPU | 2核 | 2核 |
| 内存 | 2G | 4G |
| 硬盘 | 10G | 40G |
| 网络 | 能访问 GitHub | 能访问 GitHub + OpenAI API |
| 权限 | root 或 sudo 免密 | root |

## 自动安装的依赖

deploy.sh Step 1 会通过 apt 安装：

```bash
sudo apt install -y python3 python3-pip python3-venv nodejs npm git curl wget
```

| 依赖 | 用途 | 版本要求 |
|------|------|---------|
| python3 | Hermes Agent 核心运行时 | 3.10+ |
| python3-pip | Python 包管理 | — |
| python3-venv | Python 虚拟环境 | — |
| nodejs | 部分脚本依赖 | 18+ |
| npm | Node.js 包管理 | — |
| git | 版本控制（克隆产品包） | 2.0+ |
| curl | HTTP 请求（安装/调用） | — |
| wget | 文件下载 | — |

## Hermes Agent

deploy.sh Step 2 会自动安装：

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

这会安装：
- Hermes Agent CLI
- Python 虚拟环境（~/.hermes/venv）
- 依赖的 Python 包（pyyaml, requests 等）

## Python 包依赖

以下包在 Hermes 安装时自动装好，不需要手动 pip install：

| 包名 | 用途 |
|------|------|
| pyyaml | 配置文件解析 |
| requests | HTTP 请求 |
| markdown | Markdown 转 HTML（PDF 用） |
| sqlite3 | 会话数据库（内置） |

如果遇到 `ModuleNotFoundError`，手动安装：

```bash
pip3 install pyyaml requests markdown
```

## 网络要求

| 目的 | 地址 | 端口 |
|------|------|------|
| 安装 Hermes | github.com | 443 |
| 克隆产品包 | github.com | 443 |
| LLM API 调用 | 你的 API 地址 | 443 |
| 天气查询 | wttr.in | 80 |
| Web 搜索 | 所配置的搜索引擎 | 443 |

如果服务器在内网，需要配置代理：

```bash
export http_proxy=http://代理IP:端口
export https_proxy=http://代理IP:端口
```

## 常见问题

### Q: Python 版本太低？

```bash
# 查看版本
python3 --version

# 如果低于 3.10，安装新版本
sudo apt install -y software-properties-common
sudo add-apt-repository ppa:deadsnakes/ppa
sudo apt install -y python3.10
```

### Q: Node.js 版本太低？

```bash
# 用 nvm 安装最新版
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
source ~/.bashrc
nvm install 18
```

### Q: sudo 需要密码？

```bash
# 给当前用户配置免密 sudo
# 用 root 执行：
visudo
# 加一行：your_username ALL=(ALL) NOPASSWD:ALL
```

### Q: GitHub 不可达？

```bash
# 测试连通
curl -s --max-time 5 https://github.com

# 如果超时，配置代理
export https_proxy=http://你的代理:端口
git config --global http.proxy http://你的代理:端口
```

### Q: 磁盘空间不足？

```bash
# 查看磁盘使用
df -h

# 清理 apt 缓存
sudo apt clean
sudo apt autoremove

# 清理旧内存
sudo apt remove --purge $(dpkg -l 'linux-*' | sed '/^ii/!d;/'"$(uname -r | sed "s/\(.*\)-\([^0-9]\+\)/\1/")"'/d;s/^[^ ]* [^ ]* \([^ ]*\).*/\1/;/[0-9]/!d')
```
