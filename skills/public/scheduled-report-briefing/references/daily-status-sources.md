# "今天完成了什么 / 明天该做什么" 汇报数据源

> 适用:晚间复盘 cron 与 ad-hoc 问答(用户晚上问"今天完成/明天计划"时)。
> **关键前提:22:00 晚间复盘跑之前,当日日志文件是模板**(只有健康打卡等预填),必须从其他源重建当天事实,不能只说"没记录"。

## 证据链(按顺序)

1. **当日日志模板**:`vault/日志/每日/YYYY-MM-DD.md` —— 复盘前只有预填("健康打卡"等),"今日概述/明日计划"是"(晚间复盘填充)"占位
2. **cron 输出目录**:`~/.hermes/cron/output/<job_id>/<时间戳>.md`,按文件名时间戳筛"今天"
   - 晨报 2e674bd6b476(含昨日用量/今日待办,可直接引用)
   - 用户习惯整理 de283d301896(含今日对话提取 + 新增习惯条目)
   - Token用量结算 376e5b7002a3 / 服务器监控 e4e421801189(no_agent 任务输出只有 header,silent 属正常)
   - 决策通道检查 36f35d0112ff(双向问答闭环状态)
   - once 提醒类(如 1ccad25f3377 双Hermes收尾)记录当天下发清单,可对照勾进度
3. **会话历史**:session_search 查当天主会话;习惯整理 cron 注入的【今日对话提取】更省 token
4. **明日自动任务**:`vault/entities/定时任务清单.md`(晨报/习惯整理/技能推荐/晚间复盘/知识库整理/目录更新/用量结算/监控)
5. **Windows 侧状态**:投稿箱(有没有投稿)、`vault/用量/win/`(有没有结算文件)、frp SSH 探测(在线与否)

## 汇报格式(用户偏好)

- ✅ 今日完成:每条一行,最好带来源(日志/cron 输出/画像)
- ⏳ 未完成/明日:区分 ①系统自动任务(到点照常跑)②人工待办(等用户/等 Windows 上线)
- 收尾给一句"今晚/明天会自动跑什么",让用户有掌控感
- 注意 windows-hermes-ops 的状态汇报纪律:Windows 侧无痕迹 ≠ 未完成
