# AI工作室系统 · 从零部署指南

> 适用环境：全新 Ubuntu 22.04 服务器（VMware/云服务器/ECS 均可）

---

## 系统要求

| 项目 | 最低 | 推荐 |
|------|------|------|
| 系统 | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |
| CPU | 2核 | 2核 |
| 内存 | 2G | 4G |
| 硬盘 | 20G | 40G |
| 网络 | 能访问外网 | 能访问外网 |

## 部署步骤

### Step 1：系统准备

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y python3 python3-pip python3-venv nodejs npm git curl wget
```

### Step 2：安装 Hermes Agent

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
source ~/.bashrc
```

验证：
```bash
hermes --version
```

### Step 3：上传产品包

从 Windows 电脑 PowerShell 执行：

```powershell
# 方法1: scp（推荐）
scp -r D:\产品模板\* root@服务器IP:~/ai-studio/

# 方法2: 如果产品包在其他位置，改路径即可
scp -r C:\Users\你的用户名\Downloads\产品模板\* root@服务器IP:~/ai-studio/
```

### Step 4：运行安装脚本

```bash
cd ~/ai-studio
bash install.sh
```

脚本会自动：
- 创建目录结构
- 部署 28 个脚本
- 部署 35 个技能
- 部署 2 个员工 Profile
- 部署 Vault 文档

### Step 5：配置环境变量

```bash
vim ~/.hermes/.env
```

填入以下内容（替换为你的实际值）：

```
# === 必填 ===
YOUR_API_KEY=你的API密钥
YOUR_BASE_URL=https://你的API地址/v1
YOUR_MODEL=模型名称

# === Dashboard ===
DASHBOARD_USER=admin
DASHBOARD_PASSWORD_HASH=
DASHBOARD_SECRET=

# === 微信推送（填了才有微信通知）===
WEIXIN_CHAT_ID=你的微信Chat_ID

# === 城市（天气用）===
CITY=Fuzhou

# === 同步域名（可选）===
SYNC_DOMAIN=你的同步域名
SERVER_IP=你的服务器IP
```

### Step 6：配置模型

```bash
vim ~/.hermes/config.yaml
```

找到以下三行，填入你的值：

```yaml
model:
  api_key: "你的API密钥"
  base_url: "https://你的API地址/v1"
  default: "模型名称"
```

### Step 7：验证安装

```bash
# 检查环境
hermes doctor

# 启动测试
hermes

# 发一条消息，确认能正常回复
# 输入: 你好
```

### Step 8：测试员工派活

```bash
# 测试调研员
hermes -p researcher -q "测试一下，回复OK即可"

# 测试写作员
hermes -p writer -q "测试一下，回复OK即可"
```

### Step 9：检查目录结构

```bash
ls ~/vault/
```

应该看到：
```
00-Inbox/  wiki/  流程/  工作室/  复盘/  日志/  用量/  博客/  entities/
```

### Step 10：配置定时任务

```bash
# 查看任务模板
cat ~/ai-studio/cron/jobs-template.json

# 在 Hermes 中创建任务（启动 hermes 后用 /cron 命令）
# 或参考 cron/README.md 手动创建
```

## 可选配置

### 接入微信推送

1. 部署微信 iLink 服务
2. 在 .env 中填入 WEIXIN_CHAT_ID
3. 在 config.yaml 中配置 gateway

### 接入 Notion

1. 在 .env 中填入 NOTION_TOKEN
2. 运行 `python3 ~/.hermes/scripts/notion_create_dbs.py`

### 接入 Obsidian（Windows）

1. 在 Windows 上安装 Obsidian
2. 打开 Vault → 选择服务器上的 vault 目录（通过 Syncthing 同步）
3. 或直接用本地 vault 目录

### 接入 Syncthing 三端同步

参考 `~/vault/流程/运维流程.md`

## 常见问题

### Q: hermes 命令找不到？

```bash
source ~/.bashrc
# 或重新打开终端
```

### Q: 脚本报错 ModuleNotFoundError？

```bash
pip3 install pyyaml requests
```

### Q: 知识库目录是空的？

```bash
ls ~/vault/00-Inbox/
# 把文件放进去，每天 03:00 AI 自动分类
```

### Q: 定时任务没执行？

```bash
hermes cron list
# 检查任务是否创建成功
```

### Q: 微信收不到通知？

1. 检查 WEIXIN_CHAT_ID 是否正确
2. 检查 Hermes Gateway 是否运行
3. 检查微信 iLink 是否连接
