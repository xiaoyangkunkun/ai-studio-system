# AI工作室系统 · 使用手册

## 一、系统简介

AI工作室系统是一套基于 Hermes Agent 的全自动数字员工运营体系。它不只是一个 AI 助手，而是一个完整的「AI 团队」——包含调研员、写作员等角色，配合知识管理、定时任务、复盘改进等机制，实现真正的自动化工作流。

### 核心能力

- **多员工协作**：调研员负责深度调研，写作员负责内容创作，军师负责调度
- **知识自动管理**：Inbox 自动分类、知识库自动整理、死链自动修复
- **定时自动化**：21个定时任务覆盖日报、复盘、监控、备份
- **多端同步**：通过 Syncthing 实现服务器/电脑/手机三端同步
- **成本透明**：Token 用量实时追踪，余额告警

## 二、安装部署

### 前置要求

- Linux/macOS（Windows 需 WSL）
- Python 3.10+
- Node.js 18+（部分功能需要）
- Hermes Agent（安装脚本会检查）

### 安装步骤

```bash
# 1. 安装 Hermes Agent
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

# 2. 进入产品包目录
cd ai-studio-system

# 3. 一键安装
bash install.sh

# 4. 配置环境变量
vim ~/.hermes/.env
# 填入：YOUR_API_KEY, YOUR_BASE_URL, YOUR_MODEL, WEIXIN_CHAT_ID, CITY

# 5. 检查环境
hermes doctor

# 6. 启动
hermes
```

### 配置说明

**必填项（.env）：**
- `YOUR_API_KEY` — LLM API Key
- `YOUR_BASE_URL` — API 端点地址
- `YOUR_MODEL` — 模型名称

**可选项：**
- `WEIXIN_CHAT_ID` — 微信推送（填了才有微信通知）
- `CITY` — 城市（天气用，默认 Fuzhou）
- `NOTION_TOKEN` — Notion 集成（填了才有 Notion 功能）

## 三、日常工作流

### 每日自动流程

| 时间 | 任务 | 说明 |
|------|------|------|
| 08:00 | 晨报 | 天气+用量+待办+产出，推送到微信 |
| 00:10 | Token结算 | 自动统计昨日用量 |
| 00:30 | 晚间复盘 | 总结当日工作 |
| 02:00-03:30 | 知识库维护 | 习惯提取→Inbox分类→健康度扫描→整理 |
| 04:30 | 目录更新 | 更新技能目录 |
| 07:30 | 夜间检查 | 检查任务状态 |
| 每30分钟 | 服务器监控 | 服务器状态检查 |

### 每周自动流程

| 时间 | 任务 | 说明 |
|------|------|------|
| 周日 03:00 | 自动备份 | 全量备份 |
| 周日 00:45 | 每周复盘 | 生成周报 |
| 周六 05:00-06:00 | 体检三连 | 技能→习惯→规则健康检查 |
| 周日 06:00 | SOUL周审 | 审查员工人设 |

### 手动派活

```bash
# 派调研员做调研
hermes -p researcher -q "调研XXX"

# 派写作员写文章
hermes -p writer -q "写一篇关于XXX的文章"

# 查看产出
ls ~/vault/工作室产出/
```

## 四、知识管理

### 目录结构

```
vault/
├── 00-Inbox/          # 待分类（AI自动处理）
├── entities/          # 实体/概念定义
├── wiki/              # 知识库核心
│   ├── raw/           # 原始调研报告
│   ├── entities/      # 实体页
│   ├── concepts/      # 概念页
│   └── comparisons/   # 对比分析
├── 流程/              # 工作流程文档
├── 工作室/            # 团队架构和规则
├── 复盘/              # 复盘归档
├── 日志/              # 每日/每周日志
└── 用量/              # Token统计
```

### 自动化机制

1. **Inbox 分类**（每天 03:00）：AI 自动将 00-Inbox/ 中的文件分类到对应目录
2. **知识库整理**（每天 03:30）：自动修复 frontmatter、死链、格式问题
3. **健康度扫描**（每天 03:10）：检查知识库完整性
4. **产出监控**（每天 02:30）：检查员工产出目录

## 五、员工管理

### 调研员（知远）

**职责**：深度调研、竞品分析、技术验证

**技能包**：
- deep-research — 深度调研
- grounded-citations — 引用管理
- citation-management — 引用系统化
- tavily-web — Web搜索增强
- jina-reader — JS渲染页面提取
- web-scraper — 智能网页抓取

**产出规范**：
- 格式：结构化 Markdown
- 路径：`~/vault/工作室产出/方案架构师·知远/调研报告/<主题>/`
- 命名：`YYYY-MM-DD-主题.md`

### 写作员（墨白）

**职责**：文章撰写、内容创作、去AI腔

**技能包**：
- avoid-ai-writing — 去AI腔
- humanizer — 文本人性化
- humanize-chinese — 中文去AI腔
- markdown-to-pdf — PDF交付
- data-storytelling — 数据叙事
- platform-publishing-automation — 平台发布

**产出规范**：
- 格式：Markdown（发布前转PDF）
- 路径：`~/vault/工作室产出/写作员·墨白/`
- 审稿：发布前必须老大审稿

## 六、成本控制

### Token用量追踪

- 每天 00:10 自动结算
- 数据存放在 `~/vault/用量/`
- 晨报中显示昨日用量

### 成本优化建议

1. **非高峰使用**：00:00-08:00 通常有折扣
2. **模型选择**：日常对话用轻量模型，复杂任务用重量模型
3. **缓存利用**：Hermes 自动缓存，减少重复计算

## 七、备份与恢复

### 自动备份

- 每周日 03:00 自动全量备份
- 备份位置：`~/backup/`
- 保留最近 4 份

### 手动备份

```bash
# 全量备份
bash ~/.hermes/scripts/backup_all.sh

# 恢复
cp -r ~/backup/latest/* ~/
```

### 多端同步

通过 Syncthing 实现三端同步：
- 服务器（生产环境）
- Windows 电脑（开发环境）
- 手机（查看/简单操作）

配置参考：`~/vault/流程/运维流程.md`

## 八、常见问题

### Q: 脚本报错找不到模块？

```bash
pip install -r requirements.txt
# 或单独安装
pip install pyyaml requests
```

### Q: 知识库分类不工作？

检查 00-Inbox/ 目录是否有文件：
```bash
ls ~/vault/00-Inbox/
```

### Q: 定时任务没执行？

```bash
hermes cron list
# 检查任务状态
```

### Q: 微信收不到通知？

1. 检查 .env 中 WEIXIN_CHAT_ID 是否正确
2. 检查 Hermes Gateway 是否运行
3. 检查微信 iLink 是否连接

### Q: 如何添加新员工？

1. 创建新 Profile：`~/.hermes/profiles/new-worker/`
2. 编写 SOUL.md（人设）
3. 分配技能到 `skills/` 目录
4. 在 cron 中添加相关任务

## 九、进阶配置

### 接入 Notion

1. 在 .env 中填入 NOTION_TOKEN
2. 运行 `python3 ~/.hermes/scripts/notion_create_dbs.py`
3. 晨报和待办会自动同步到 Notion

### 接入 TTS/STT

1. 在 config.yaml 中取消注释 tts/stt 配置
2. 填入对应的 provider 和 API key
3. 重启 Hermes

参考 `~/vault/流程/技能管理流程.md`
