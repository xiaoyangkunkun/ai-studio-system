# Cron 任务配置指南

## 前置条件

确保 Hermes 已安装且 `hermes cron` 命令可用。

## 配置步骤

### 1. 设置环境变量

编辑 `env-template`，填入你的配置：

```bash
WEIXIN_CHAT_ID=你的微信Chat_ID    # 微信推送目标（必填，如需微信通知）
CITY=Fuzhou                       # 你的城市（天气用）
```

### 2. 导入任务

```bash
# 方法1: 使用 hermes CLI
hermes cron create --name "每日晨报" --schedule "0 8 * * *" --script ...

# 方法2: 手动创建（推荐先理解每个任务的用途）
# 参考 jobs-template.json 中的任务定义
```

### 3. 任务说明

| 任务 | 时间 | 类型 | 说明 |
|------|------|------|------|
| 每日晨报 | 08:00 | agent | 天气+用量+待办+产出，推送到微信 |
| Token用量结算 | 00:10 | script | 自动统计昨日用量 |
| 晚间复盘 | 00:30 | agent | 总结当日工作，存到复盘目录 |
| 用户习惯整理 | 02:00 | script | 提取用户习惯变化 |
| 技能推荐 | 01:00 | agent | 搜索推荐新技能 |
| 产出Watchdog | 02:30 | script | 检查产出目录 |
| Inbox分类 | 03:00 | script | AI自动分类Inbox |
| 知识库健康度 | 03:10 | script | 扫描知识库问题 |
| 知识库整理 | 03:30 | agent | 修复格式和死链 |
| 每周备份 | 周日03:00 | script | 自动备份 |
| 目录更新 | 04:30 | script | 更新技能目录 |
| 夜间检查 | 07:30 | script | 检查夜间任务状态 |
| 投稿审核 | 周日05:00 | agent | 检查待发布文章 |
| 流程优化 | 周日05:30 | script | 分析流程信号 |
| 服务器监控 | 每30分钟 | script | 服务器状态检查 |
| 技能健康检查 | 周六05:00 | agent | 检查技能完整性 |
| 习惯体检 | 周六05:30 | script | 检查习惯规则 |
| 规则体检 | 周六06:00 | agent | 检查规则冲突 |
| SOUL周审 | 周日06:00 | agent | 审查员工SOUL |
| 用量提醒 | 周日00:30 | agent | 提醒截图备份，推送到微信 |
| 每周复盘 | 周日00:45 | agent | 生成周报 |

### 4. 推送配置

- **微信推送**: 设置 `deliver` 为你的微信 Chat ID
- **本地存储**: 设置 `deliver` 为 `local`（仅保存不推送）
- **自定义推送**: 设置 `deliver` 为 `platform:chat_id` 格式

## 注意事项

1. 部分任务有依赖关系（如晚间复盘依赖Token用量结算），请按顺序创建
2. 首次运行建议手动触发一次验证
3. 微信推送有频率限制，建议间隔≥30分钟
